## المتطلبات

- **Node.js 20+**
- **MongoDB** يعمل محلياً (`mongod`) **أو** رابط Atlas سحابي (اختر الأنسب لك)

## التشغيل السريع — Windows (PowerShell)

يحتاج الموقع لقاعدة MongoDB. الأسهل للمحلي: سكربت مدمج يشغّل MongoDB مؤقتاً بالذاكرة (بلا تثبيت).

```powershell
# 1) تثبيت الحزم
npm install

# 2) تشغيل MongoDB المحلي — نافذة PowerShell أولى (اتركها مفتوحة)
npm run mongo

# 3) تشغيل الموقع — نافذة PowerShell ثانية
npm run dev
```

ثم افتح: **http://localhost:3000**

> ملف `.env` مرفق وجاهز (MONGODB_URI=mongodb://127.0.0.1:27017/ait_tegrine).
> لاستخدام Atlas السحابي بدلاً من المحلي: عدّل `MONGODB_URI` في `.env` وستغنيك عن الخطوة 2.

## أول تشغيل — إنشاء حساب الإدارة

1. افتح الموقع واضغط **تسجيل الدخول**.
2. **حساب الإدارة يُجهَّز تلقائياً من ملف `.env`**: `ADMIN_PHONE` + `ADMIN_PASSWORD` (المرفق: `0542163526` / `12345678`).
3. عند أول تشغيل على قاعدة فارغة يبني الموقع تلقائياً بيانات بدء: مساعد + 3 أخصائيين + عميلان + موعدان + 4 خدمات + تكوينان + كتاب تفاعلي — كلها قابلة للتعديل أو الحذف من حساب الإدارة.
4. الحسابات الجديدة (مساعد/أخصائي/عميل) تُنشأ من **الحسابات** داخل حساب الإدارة، والعميل يستطيع تسجيل حساب ذاتي من صفحة الدخول.

> إن حذفت بيانات البدء كلها لاحقاً فلن تعود — البذر يعمل مرة واحدة فقط عندما يكون جدول المستخدمين فارغاً.

## نظام الجلسة (نمط طمأنينة — محسّن في v3)

منذ الإصدار 2.0.0 اعتمد الموقع **توكن HMAC-SHA256 في الهيدر** (بدل الكوكيز) — نفس معمارية منصة طمأنينة التي أثبتت موثوقية تامة:

- عند الدخول يُصدَر توكن موقّع (صلاحية 30 يوماً) ويُحفظ في جهاز المستخدم (localStorage).
- كل نداء API يُرفق التوكن تلقائياً عبر هيدر `x-auth-token` (غلاف موحّد يغطي **fetch وXHR** معاً — يشمل رفع الوسائط بشريط التقدم).
- الخادم يتحقق من التوقيع + الصلاحية + حالة الحساب في كل طلب مركزياً.
- **ميزة حاسمة**: يعمل بلا انقطاع داخل تطبيقات المعاينة/iframes ومتصفحات الهاتف التي تحجب الكوكيز — لا مزيد من "سجّل الدخول من جديد" عند الحفظ، ولا قوائم فارغة.
- لتعطيل كل الجلسات (مثلاً عند تسريب السر): غيّر `AUTH_SECRET` في `.env`.

متغيرات البيئة: انسخ `.env.example` إلى `.env` واضبط `MONGODB_URI` و`AUTH_SECRET`.

## مزايا النظام

| المجال | التفاصيل |
|---|---|
| الحسابات | إدارة / مساعد(ة) / أخصائي (نفسي، أرطوفوني، كلاهما) / عميل — تُنشأ من الإدارة فقط، مع تفعيل/تعطيل وتعديل وحذف |
| المواعيد | حجز بالنقر على الوقت (شبكة أوقات من إعدادات المركز وساعات الأخصائي)، منع تصادم الأوقات، حالات (بانتظار/مؤكد/منتهي/ملغى) |
| التذكيرات | إشعار بموعد **الغد** + إشعار **قبل ساعة** لكل الأطراف (عميل + أخصائي + الإدارة) تلقائياً |
| الإشعارات VAPID | Web Push تعمل حتى والموقع مغلق (PWA + Service Worker) — زر التفعيل في جرس الإشعارات |
| اللغات | عربية أساس + FR/EN مع مبدّل في الهيدر، وتفعيل/تعطيل كل لغة من الإعدادات |
| حجم النص | أزرار تكبير/تصغير النص في الهيدر (وداخل القائمة على الجوال) |
| الإخفاء السريع | اضغط **شعار المركز 3 مرات** أو زر **إخفاء سريع** في القائمة — شاشة محايدة فورية، نقرتان مزدوجتان للعودة |
| الوسائط | معرض المركز (صور + فيديو) يُدار من الإعدادات — رفع إلى قرص الخادم وبث فيديو بجودة متكيفة (Range) |
| الخدمات | أيقونات إيموجي من كيبورد الهاتف، صور غلاف، تصنيفات، أسعار، تفعيل/تعطيل، معاينة وتفاصيل |
| التكوينات | صور متعددة بتمرير لمسي + برنامج حصص (تاريخ + بداية + نهاية + عنوان) |
| E-books | تضيفها الإدارة فقط (عنوان + نبذة + غلاف base64 + فقرات وأسطر إجابات) — القراءة داخل الموقع فقط بلا تحميل، يجيب العميل داخل الأسطر ويحفظ، والإجابات تظهر **للإدارة وللأخصائي المعالج فقط** |
| موقع العيادة | خريطة تفاعلية + زر **GPS** + سحب يدوي للمؤشر (تُحدَّث الإحداثيات في إعدادات المركز) |
| سلايدر الوسائط | صور/فيديو base64 ترفعها الإدارة وتظهر أعلى الرئيسية قبل بطاقات الخدمات بتمرير لمسي سلس |
| واتساب | زر عائم بأيقونة واتساب الحقيقية «راسلنا على واتساب» (الرقم من الإعدادات) |
| التواصل الاجتماعي | أيقونات حقيقية قابلة للضغط (Facebook/Instagram/TikTok/YouTube/Telegram) من الإعدادات |
| صفحات المحتوى | أسئلة شائعة، عن المركز، الخصوصية، شروط الاستخدام — تُحرر كاملة من الإعدادات |
| التصميم | RTL كامل، تجاوب تام من الهاتف إلى الشاشات الكبيرة، هوامش آمنة، لا نصوص مقطوعة، أنيميشن ناعم |

## ملاحظات تقنية

- **قاعدة البيانات:** MongoDB/Mongoose — تُنشأ المجموعات والفهارس تلقائياً عند أول تشغيل.
- **مفاتيح VAPID:** تُولَّد تلقائياً عند أول تشغيل وتُخزَّن في قاعدة البيانات (مجموعة settings).
- **الصور:** تُخزَّن base64 داخل MongoDB (تُصغَّر تلقائياً قبل الرفع لتخفيف الحجم).
- **المجدول:** يعمل داخل عملية الخادم (فحص كل 5 دقائق) — يرسل تذكير الغد مرة واحدة وذاك قبل الساعة مرة واحدة لكل موعد.
- **الجلسات:** كوكي httpOnly + جلسات في MongoDB، صلاحيات مفروضة على كل مسارات API.
