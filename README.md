# مركز آيت تقرين النفسي — Centre Psy Aitigrine

منصة ويب متكاملة لمركز استشارات نفسية وأرطوفونية — **الإصدار 3.10.0**

- خمس لغات كاملة: العربية · الفرنسية · الإنجليزية · التركية · الإسبانية (تفعيل/تعطيل من الإعدادات)
- تطبيق صفحة واحدة (Next.js 16) + MongoDB (Mongoose) + GridFS للوسائط
- يعمل على Windows / Linux / macOS بنفس الأوامر

---

## التشغيل السريع

```bash
npm install          # تثبيت الحزم
npm run mongo        # تشغيل MongoDB المحلي (بيئة معاينة)
npm run dev          # الموقع على http://localhost:3000
```

للإنتاج: `npm run build` ثم `npm start` مع رابط MongoDB خارجي في `.env`.

### ملف البيئة `.env`

انسخ `.env.example` إلى `.env` وعدّل القيم:

| المتغير | الوصف |
|---|---|
| `MONGODB_URI` | رابط قاعدة البيانات (Atlas للإنتاج) |
| `AUTH_SECRET` | عبارة سرية طويلة لتوقيع التوكنات |
| `ADMIN_PHONE` / `ADMIN_PASSWORD` | بوابة الإدارة (يُنشأ الحساب تلقائياً) |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | دخول Google (اختياري — v3.9) |
| `NEXT_PUBLIC_CENTER_WHATSAPP` | رقم واتساب احتياطي إذا خلت إعدادات المركز (v3.9) |
| `PUBLIC_BASE_URL` | عنوان الموقع العام (للـ OAuth redirect) |

### ★ إصلاح خطأ `redirect_uri_mismatch` (دخول Google)
هذا الخطأ يعني أن **رابط العودة المسجّل في Google Console لا يطابق حرفياً** الرابط الذي يستعمله الخادم. الحل الدقيق:

1. ادخل بحساب الإدارة → **إعدادات المركز → تبويب «الأدوات» → بطاقة «دخول Google»**
2. **انسخ** رابط العودة المعروض (نمطه: `https://<your-domain>/api/auth/google/callback`)
3. في [Google Cloud Console](https://console.cloud.google.com) → **APIs & Services → Credentials → OAuth 2.0 Client ID** → خانة **«Authorized redirect URIs»** أضف الرابط **حرفياً** (بدون شرطة مائلة في النهاية، بدون فراغات، نفس `http/https` ونفس النطاق والمنفذ)
4. احفظ في Google ثم أعد المحاولة — يستغرق التغيير أحياناً دقائق معدودة للتفعيل
5. إن كان الموقع خلف نطاق عام فعّل أيضاً `PUBLIC_BASE_URL=https://<your-domain>` في `.env` لضمان ثبات الرابط

> ملاحظة: أي اختلاف (حتى منفذ تجريبي مثل `:3100` أو `localhost` مقابل نطاق عام) يسبب نفس الخطأ — سجّل كل رابط تستعمله فعلياً (التجريبي والإنتاجي معاً).

## الجديد في الإصدار 3.10.0

- **الفاتورة في صفحة واحدة مضمونة**: أُصلح الجذر — التذييل كان يُرسم عند حافة الصفحة فيفيض سطر واحد لصفحة ثانية؛ صار مرفوعاً بنصوص مضمونة السطر الواحد بالقياس الفعلي، وكل المحتوى ينتهي قبل منتصف الصفحة بفاصل آمن
- **توحيد Mode و Désignation في الفاتورة**: سطر الجدول يذكر وضع الجلسة بنفس صياغة سطر Mode (Séance — présentielle au centre / à distance) + قصّ عمود DÉSIGNATION بالقياس الفعلي فلا يتجاوز عمود MONTANT أبداً
- **نافذة الهاتف الإلزامية لحسابات Google**: بعد أول دخول بـ Google فقط، نافذة غير قابلة للتجاوز تُلزم العميل بإدخال رقمه الحقيقي (تحقق 9-15 رقماً + تطبيع جزائري + فحص التفرد) ويُحفظ في ملفه مكان الصيغة الداخلية g-… ويبقى تابعاً لنفس الحساب دائماً
- **الشات بوت يفهم أسئلته أخيراً**: أزرار الأسئلة السريعة ترسل «نية» مباشرة فتجيب الإجابة الصحيحة حرفياً بكل اللغات بلا تخمين؛ محرك النص الحر تحسّن بأولويات تكسر التعادل (كانت «ما هي أوقات العمل؟» تجيب رد الحجز!) + مرادفات موسعة (دوام/عيادة/ثمن/شحال/نلغي…)
- **الإعدادات بخمس لغات كاملة**: كل الحقول الثلاثية صارت خماسياً (اسم المركز، الشعار النصي، نبذة، العنوان، تصنيفات الخدمات والتكوينات، العبارات الترحيبية، التخصصات) — التركية والإسبانية مثل الفرنسية تماماً
- **سجل التدقيق يُحذف تلقائياً بعد 3 أيام** (TTL في قاعدة البيانات + تنظيف احتياطي) **+ زر تفريغ فوري** في مكانه للإدارة مع نافذة تأكيد
- **تعديل وحذف كل التخصصات**: الافتراضية لم تعد مقفلة — زر تعديل بنموذج خماسي اللغات وزر حذف بنافذة تأكيد للجميع؛ المحذوف من الافتراضية لا يعود عند إعادة التشغيل (رموز ثابتة)
- **صفحة اتصل بنا بالتركية/الإسبانية**: كان العنوان يظهر بالفرنسية وأسماء الأيام بالإنجليزية — صارت بخمس لغات مع سقوط ذكي، وكذلك وثائق المرضى
- **ترجمة شاملة متوازنة**: 862 مفتاحاً × 5 قواميس متطابقة تماماً

## الجديد في الإصدار 3.9.0

- **الفاتورة بالفرنسية دائماً**: كل فواتير PDF تُولَّد بالفرنسية كاملة بتخطيط منظم LTR (بغضّ النظر عن لغة الواجهة) — مع معالجة سليمة لأي قيم عربية (أسماء) داخل النص. ملف جديد: `facture-<num>.pdf`
- **إلغاء الاقتطاع «...» نهائياً**: النصوص كاملة في كل الصفحات والنوافذ (سجل التدقيق، الأسماء، العناوين، البطاقات…) مع التفاف محترم للتجاوب دون تجاوز إطار الشاشة
- **الشات بوت v3.9**: زر إغلاق (×) دائم يخفي الودجت كلياً من الواجهة لبقية الجلسة (نفس نمط واتساب) + نافذة أطول بمساحة أجوبة مرنة (flex) لا تضيق لصالح الأسئلة السريعة
- **دخول Google مكتمل الإشارات**: رسالة نجاح واضحة بعد العودة من Google، ورسالة سبب الفشل الصريح (كود/توكن/بروفايل/حساب معطل) — لا صمت بعد التحويل بعد اليوم
- **صفحة مواعيدي أعيدت هيكلتها**: بطاقة عمودية (صف معلومات + شريط أزرار بعرض كامل) — لا نصوص عمودية ولا ضغط؛ قائمة التقويم تعمل بالنقر على الهاتف (كانت hover فقط)
- **إصلاح كاش الفواتير في PWA**: كانت `/api/invoices` تُخدم cache-first فيظهر PDF قديم — صارت network-first
- **زر واتساب لا يختفي**: سلسلة احتياطية (إعدادات المركز ← هاتف المركز ← `NEXT_PUBLIC_CENTER_WHATSAPP`)

## ميزات المنصة (منذ v3.8)

### 1. لوحة إحصائيات حية برسوم بيانية
الحجوزات الشهرية (آخر 6 أشهر حسب الحالة)، الخدمات الأكثر طلباً، منحنى نمو العملاء — Recharts، تحديث تلقائي كل 45 ثانية.

### 2. تصدير البيانات Excel/CSV
الحجوزات، الحسابات، الفواتير — CSV بترميز UTF-8 + BOM يفتح مباشرة في Excel، بعناوين **بلغة واجهة المستخدم** (5 لغات) وبتوقيت الجزائر GMT+1 (Africa/Algiers). من: الإعدادات → الأدوات.

### 3. سجل تدقيق Audit Log
توثيق تلقائي لكل عملية حساسة: من فعل ماذا ومتى ومن أي IP — الدخول (نجاح/فشل/حجب)، المواعيد، الكوبونات، الشهادات، الفواتير، النسخ الاحتياطي، التصدير، الإعدادات، الحسابات. عرض/بحث للإدارة من تبويب الأدوات.

### 4. نسخ احتياطي بضغطة
ملف ZIP كامل: كل مجموعات قاعدة البيانات (JSON) + كل وسائط GridFS + فهرس — تدفقياً دون استهلاك الذاكرة.

### 5. وضع عدم الاتصال (PWA)
Service Worker v3.9: الصفحات المزارة تعمل بلا إنترنت، الوسائط تُخزَّن بعد أول مشاهدة، صفحة «بلا اتصال» أنيقة ثلاثية اللغة عند العجز الكامل. يُسجَّل SW تلقائياً من أول زيارة.

### 6. دخول عبر Google OAuth
زر «الدخول بحساب Google» في بوابة العملاء — **بجانب** الدخول التقليدي بالهاتف/كلمة المرور (لا يُستبدل). أضف مفاتيح GOOGLE في `.env` ويعمل فوراً؛ بدونها يظهر تنبيه واضح وكل شيء آخر يعمل. بعد العودة من Google تظهر رسالة نجاح أو سبب الفشل الصريح، والرابط الدقيق المطلوب في Google Console يظهر للإدارة في: الأدوات → بطاقة دخول Google.

### 7. حماية متقدمة
- حجب محاولات الدخول: 5 فشلات للهاتف → حجب 15 دقيقة (وعتبة IP أعلى = 20 لصعق الهجمات الآلية دون الإضرار بالشبكات المشتركة)
- رؤوس أمان لكل الاستجابات: nosniff، Referrer-Policy، X-Frame-Options، frame-ancestors، Permissions-Policy، HSTS
- توثيق كل محاولة فاشلة/محجوبة في سجل التدقيق

### 8. المساعد الذكي Chatbot
ودجت عائم في كل الصفحات: ردود فورية على الأسئلة الشائعة (حجز، أسعار، خصومات، عن بُعد، تخصصات، تكوينات، موقع…) بخمس لغات + أزرار توجيه مباشر + زر إغلاق يجعل الودجت يختفي كلياً (يعود في زيارة قادمة) + نافذة متجاوبة بمساحة أجوبة كاملة. يعمل بلا خدمات خارجية وبلا تكلفة.

### 9. شهادات وقصص نجاح
صفحة عامة تديرها الإدارة — **سياسة الخصوصية**: الاسم يُحوَّل تلقائياً لصيغة محمية (الأول + حرف) ولا يظهر اسماً كاملاً أبداً للزوار؛ الاسم الحقيقي يبقى سرياً للإدارة. اعتماد/تعديل/حذف + تمييز «قصة نجاح».

### 10. إضافة الموعد للتقويم
زر «التقويم» على بطاقات المواعيد المؤكدة: رابط Google Calendar مباشر + ملف iCal (.ics) قياسي يعمل مع Apple/Outlook مع تذكير قبل ساعة.

### 11. فواتير PDF تلقائية — بالفرنسية دائماً
عند إنهاء الجلسة أو أداء المبلغ تُولَّد فاتورة PDF **بالفرنسية كاملة** بتخطيط منظم (Facture de séance، رقم INV-YYYYMM-XXXXXX، المبالغ، الخصم، الكوبون) بشعار المركز وبياناته، وتُحفظ في GridFS وترتبط بملف العميل — تنزيلها من بطاقة الموعد (للإدارة والأخصائي).

### 12. رموز خصم وعروض (كوبونات)
الإدارة تنشئ كوبونات نسبة % أو مبلغ ثابت مع: تاريخ انتهاء، حد استخدام، أدنى سعر، وصف ثلاثي اللغة. العميل يدخل الكود في خطوة التأكيد → تحقق خادمي كامل → يُخصم المبلغ ويُسجَّل على الموعد والفاتورة، وعدّاد الاستخدام يتزايد تلقائياً.
